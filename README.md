# Cpp
 
A collection of C++ practice projects — mini console applications built while learning core C++ concepts like OOP, file handling, and data structures.
 
## Projects
 
| Project | Description |
|---|---|
| `Bank Management.cpp` | A console-based banking system — create accounts, deposit, withdraw, and check balances. |
| `Contact Management.cpp` | A simple contact book to add, view, search, and delete contacts. |
| `LMS.cpp` | A Library Management System for tracking books — issue, return, and manage records. |
| `Snake game.cpp` | A classic console-based Snake game. |
 
## How to Run
 
Each file is a standalone C++ program. Compile and run with g++ (or any C++ compiler):
 
```bash
g++ "Bank Management.cpp" -o bank
./bank
```
 
Replace the filename for whichever project you want to run:
 
```bash
g++ "Contact Management.cpp" -o contacts
./contacts
 
g++ "LMS.cpp" -o lms
./lms
 
g++ "Snake game.cpp" -o snake
./snake
```
 
## Purpose
 
This repo is for practicing C++ fundamentals — things like classes and objects, control flow, arrays/vectors, and basic console I/O — through small, self-contained projects rather than one big application.
